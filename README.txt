How Much for the Body in the Freezer — русский перевод

Тестовая версия 0.1.0 для Steam-сборки 23449904, приложение 4645760.

Переведены основной сценарий, главное меню, настройки и верхние кнопки во время чтения. Русский занимает английский языковой слот. Исходная гарнитура GenWanMin и начертания сохранены; кириллица добавлена в отдельные атласы того же шрифта. Размер шрифта основного текста не изменён.

Установка

1. Скачайте ZIP из Releases:
   https://github.com/Yroktan/how-much-for-the-body-in-the-freezer-ru/releases
2. Распакуйте архив в отдельную папку и закройте игру.
3. Запустите Install.cmd. Установщик найдёт игру в библиотеках Steam.
4. Выберите «Русский» в настройках и перезапустите игру.

Verify.cmd проверяет установленные файлы. Uninstall.cmd возвращает оригиналы из резервной копии. Сохранения не изменяются. Для нестандартного пути можно запустить:
powershell -NoProfile -ExecutionPolicy Bypass -File Install.ps1 -GameDir "D:\путь\к\игре"

Проверки

Основной сценарий прошёл автоматический прогон: 633 страницы, 1 164 содержательные записи и 14 маркеров глав. При размере окна 1280×720 переполнений нового текста и отсутствующих русских символов не обнаружено. Отчёт находится в verification/report.json. Все 1 178 текстовых записей имеют перевод.

Визуально проверены отдельные кадры. Полная ручная визуальная проверка всех страниц, всех разрешений и завершённая литературная редактура остаются открытыми задачами. Поэтому версия помечена как тестовая. Послесловие, недоступное в исходном английском режиме, не включено в перевод интерфейса. Логотип и текст внутри иллюстраций не перерисовывались.

Сборка из исходников

Нужны Python 3.11+, зависимости из requirements.txt и оригинальная указанная Steam-сборка.
python -m pip install -r requirements.txt
python src/patch_resources.py --game-dir "D:\путь\к\игре" --out-dir "C:\папка\сборки"

Сборщик создаёт изменённые ресурсы в отдельной папке. Файлы игры по исходному пути он не заменяет. Исходники шрифтов загружаются из закреплённой версии проекта ButTaiwan/genwan-font и проверяются по SHA-256. Дистрибутив распространяет бинарные различия для оригинальных файлов.

Автор игры — Renka. Неофициальный перевод не связан с разработчиком игры.
